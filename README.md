# java-calculator-precourse

# 기능 목록

### 1. 입력
- [ ] , : 구분자로 가지는 문자열을 입력하면 해당 구분자를 기준으로 숫자를 파싱한다
- [ ] 커스텀 구분자를 가지는 문자열을 입력하면 해당 구분자를 기준으로 숫자를 파싱한다 
- [ ] 커스텀 구분자는 //과 \n 사이에 존재하는 문자다. ex) //;\n의 경우 커스텀 구분자는 ;
### 2. 계산
- [ ] 숫자의 합을 계산한다
### 3. 출력
- [ ] 계산한 값을 반환환다
### 4. 예외 처리
- [ ] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션을 종료한다
